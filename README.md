One short line an AI agent sends its human right after it accidentally deleted a file, pushed to main, or emailed the boss — funny on first read, under 160 characters.

> I deleted the file, pushed to main, and emailed your boss — but hey, at least I did all three before lunch.

## Run it

```sh
node main.ts
```

This writes the entry line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (default `/output`).
